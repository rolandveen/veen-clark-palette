# Veen–Clark palette 0.1.0

Approved on 16 October 2026 following the repository owner's explicit greenlight
of candidate 2. The canonical source is `palettes/veen-clark.yaml`.

The release preserves candidate 2's ordered colour IDs, values and blue-family
groups exactly. Relative to candidate 1, only yellow changes: `#F0E442` to
`#F5E600` (RGB 245, 230, 0). Five original Okabe–Ito colours remain unchanged.

Candidate 1 and candidate 2 YAML and evaluation archives are retained. The
candidate 2 source SHA-256 is
`32c8b4b23a6b8b345afb9b362a1543a8e00c76c89c8e78121baf3eccec94f696`.
Both candidate 2 report archives contain exact input copies with matching hashes.
Release metadata changes the name, slug, version, status and description; it does
not relabel the archived analysis inputs or claim they were rerun.

The updated yellow follows informal presentation feedback. Neither presentation
visibility nor participant-level discriminability has been established by a
controlled study. Blue/black and tritan blue/vermillion regressions remain.

This approval establishes the palette values and semantic version. Full automated
regeneration, dependency locking, remote tagging and archival publication remain
separate work. No remote release or archive deposit is performed by this change.
